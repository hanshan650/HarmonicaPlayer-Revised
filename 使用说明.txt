HarmonicaPlayer 使用说明

一、开始使用
1. 解压整个发布压缩包，运行 HarmonicaPlayer.exe，无需另装 .NET。
2. 点击“导入 TXT”，选择 UTF-8 曲谱。支持旧纯音符TXT和本版保存的新格式；音符编辑区不要放标题、歌词或文件头。
3. 确认“速度（BPM）”：优先文件头，其次文件名bpm100等标记，否则沿用当前有效速度并提示。数值越大越快。只有节奏模式，空格、换行和小节线不增加停顿。
4. 初次启动默认勾选“仅日志测试”：只检查播放流程，不发送键鼠，也不发声。
5. 实际演奏时取消“仅日志测试”，进入游戏口琴界面，按开始键（默认 F6）。松开快捷键后倒计时3秒，不弹确认窗口。
6. 停止键默认 F8，可在“自定义快捷键”中修改。演奏期间除停止键外不要触碰鼠标键盘；切换窗口会停止。
7. 游戏建议使用无边框模式；遇到输入权限问题时，以管理员身份运行并确认权限与游戏匹配。
8. 修改曲名、速度、音符间隔或谱面后，标题出现*。点击“保存 TXT”或“另存为”，保存含曲名、BPM和间隔的新格式。旧谱首次保存必须使用不同文件名，保留原谱。
9. 关闭、导入、新建前若有未保存修改，可保存、放弃或取消。保存失败不会关闭窗口或丢弃当前谱面。演奏期间不能编辑或保存。
10. 修改BPM不会自动改文件名；文件头与文件名冲突时以文件头为准。不含文件头的旧版本不识别新格式，旧谱请另存一份纯正文TXT。
11. 导入时自动读取文件头@gap，例如@gap=30表示间隔30毫秒。未写时固定使用20毫秒，旧谱也一样，不沿用上一首的间隔。填写范围10～5000的整数；有填写但无效时会报错，不会偷偷改回默认值。

二、曲谱写法
中音：1～7；高音：【1】～【7】；低音：（1）～（7）。升半音：#1、【#1】。
最高 do：【【1】】，时值写在括号外，例如【【1】】:1.25。映射右键＋逗号，游戏实际音高需实测确认。
普通音符1拍；5_为半拍；5__为四分之一拍；5.为1.5拍；5_.为0.75拍。
5 —为2拍；0为休止1拍；0_为休止半拍。延长符不会重新触发音符。
指定总拍数：5:1.25、【1】:2.5、0:0.25。拍数大于0且不超过64。
冒号写法不能混用附点、下划线或延长符；与下一音用空格分开。
音符间隔会缩短每个音的实际按住时间，但不会改变总节奏。过短的音会提示降低 BPM 或减小间隔。

三、常见问题
• 顶部红色区域出现错误：阅读具体原因。曲谱错误可点击“定位曲谱错误”跳到对应字符；速度和间隔错误请修改对应设置。
• 开始按钮不可用：按钮下方会显示原因。请先修正曲谱或设置；实际演奏还要求停止快捷键可用。
• 热键被占用：点击“修改快捷键”更换，或关闭占用程序后“重试注册”。管理员权限不能解除快捷键占用。开始热键冲突时仍可用开始按钮；停止热键冲突时禁止实际演奏，但不妨碍有效谱子的日志测试。
• 日志滚动但没有声音：“开始”＋“仅日志测试”仍不发声。本地声音请点击“从头试听”或“从光标试听”；游戏声音需取消日志测试并进入游戏。
• 倒计时后提示目标窗口错误：请切到游戏口琴界面，或直接在游戏里按开始键。
• 游戏无反应：检查是否仍勾选日志测试、是否进入口琴界面、权限是否匹配；可尝试英文输入法和无边框模式。程序发送成功不保证游戏接受输入。
• 顶部保留“上次操作”错误：处理其原因后重试，或点击“清除上次操作提示”。曲谱和热键当前错误需修复后才会消失。
• 在长弓溪谷船上被别人拉走后按键失效：原因尚未确认，本版没有修复；先停止，尝试上岸并重新进入口琴界面，避免在移动船上演奏。
• 关闭时提示按键释放失败：按提示手动按下再松开相关键，然后重试关闭。

AI 转谱规则见同目录“ai转谱模板.txt”；附带曲谱见“简谱”文件夹（若已打包）。

四、本地声音试听
1. 导入或编辑曲谱，确认BPM和间隔，点击“从头试听”立即发声，无倒计时。
2. 点击正文中的音符，再点“从光标试听”，从该音播到曲末；空白/小节线/前置括号/#选下一音，时值/闭括号选所属音，末尾选最后一音。
3. 当前音符数字会高亮，显示进度、已试听和剩余时间。停止后恢复开始试听前的编辑光标。
4. 使用原“停止”按钮或有效的停止快捷键结束。开始游戏演奏与试听不能同时进行。
5. 试听期间锁定正文、曲名、BPM、间隔、导入/新建/保存/导出；停止后编辑，再试听即使用最新内容。
6. 音量可边听边调，默认60%；0%静音。自动保存到软件设置，不写进曲谱或MIDI。
7. 中音1=C4、低音1=C3、高音1=C5、最高do=C6。音色为VCSL的Hohner Special 20真实口琴录音，不是游戏录音。
8. 每音末尾按gap留白，不改变总拍数。试听和MIDI不模拟游戏12ms按键准备；仍沿用游戏最短音校验。
9. 音频设备错误在顶部提示，可检查默认扬声器/耳机后重试。无声时检查试听音量、系统混音器、默认输出设备及谱子是否全为休止。
10. 本地试听无需管理员权限、不发任何游戏键鼠；不受“仅日志测试”勾选影响。快捷键冲突时可用按钮控制。不支持暂停。

五、导出 MIDI
1. 点击“导出 MIDI”，选择.mid保存路径。导出当前编辑中的整首，不是光标以后的部分。
2. 文件为标准单轨MIDI，保留音高、BPM、时值、gap留白和休止。外部播放器须支持MIDI。
3. MIDI记录音符和音色指令，不包含试听音频。选择GM口琴音色，但最终声音由外部播放器音源决定。
4. 试听音量不写入MIDI；导出不替代“保存 TXT”，不会消除未保存星号。
5. 导出失败保留已有目标文件；取消导出不改变曲谱。非法曲谱请按顶部提示修正。
6. 不支持MIDI导入、动态BPM、和弦或播放列表。

六、音色与短音处理
1. 内置真实口琴采样（VCSL 的 Hohner Special 20，CC0），无需联网或安装音源插件；中音1=C4，未逐音录制的音由邻近采样变调补齐，低音区降调。
2. 长音用平滑循环延续，保留原音符时值和间隔；每个音末尾有真实 Release 收音，通常以45ms平滑衔接，不占用gap、不延长节奏。
3. 短音（不超过300ms）改用稳定片段和平滑起止，避免连续短音的“突突”感；较长音逐渐恢复原始起音和真实尾音，并按比例平滑淡出。
4. AudioExamples内含可对比的离线WAV，可先比较听感再构建程序。采样已编进EXE；覆盖源码时必须包含Assets/Harmonica目录，Build-Release.ps1会把来源与CC0授权说明放入发布包。
5. 导出的MIDI不含这些录音，外部播放器音色可能不同。Python仅用于开发者重新制作采样，正常构建和运行不需要。

七、导入 MIDI
1. 点击“导入 MIDI”，选择 .mid 或 .midi 文件（标准 MIDI Format 0/1，最大16MB）。SMPTE 计时和 Format 2 会提示不支持。
2. 多条含音符的轨道会在导入时弹窗列出（音轨号、名称、音数、音域、平均音长、同时发声音数），可当场选一条；默认优先选中音符最多的一条。导入后也可在“演奏音轨”下拉框里随时换轨，不必重新导入。
3. 音高映射到口琴音域（低音1～高音7，另含最高do）。先整体八度移调，仍超范围的个别音再折回八度，局部音程可能变化，提示区会注明数量。
4. 时值以四分音符一拍换算，支持整拍、半拍、附点、十六分音符和三连音；速度取 MIDI 的第一个速度事件，范围为20～300。
5. 曲名取轨道名或文件名；导入后谱面进入编辑器，可继续修改、试听、导出或“保存 TXT”。原 .mid 不会被修改或覆盖；保存时请另存为 TXT 文件名。
6. 若曲中最短音过短，程序会自动把速度降到可演奏值，提示区会写明“速度已从X BPM自动调整为Y BPM（音高与时值不变，播放放慢）”；该判断与试听／演奏使用同一最短音校验。
7. 导入不改变“仅日志测试”等设置，也不写回 MIDI；MIDI 只包含音符与速度，不含试听采样。

八、导入 JSON
1. 点击“导入 JSON”，选择 GTIartist 曲谱（format 为 gtiartist-score-v1，notes 里是 MIDI 音高加秒数）或任何含 notes 数组（pitch/start/duration）的 JSON 文件。
2. 多音轨曲谱只演奏一条音轨：导入时会弹窗列出所有音轨（音轨号、名称、音数、音域、平均音长，以及有多少处同时发声），可当场选一条；默认选中编号最小的一条（GTIartist 的第一声部，通常就是主旋律）。导入后可用“演奏音轨”下拉框随时换轨，不必重新导入。同一条音轨内同时发声的音保留最高音，后起的音会截断被它打断的长音，不会被整条吞掉。
3. 保真优先，不再为个别短音自动降速：导入后提示区会写明有多少个音短于可按住下限，并给出“调小音符间隔”或“降到X BPM”的建议；预审面板也有同样提示，但不会阻止试听／演奏。过短的音按能按住的最长时间触发，游戏里可能不发声。
4. 没有 bpm 字段时，程序根据最小时间网格推断速度（例如网格30.99ms推断为121 BPM）；网格不统一（如分段变速）时按120 BPM显示并提示，该速度只是标签，演奏仍按原文件的绝对时间对齐。若 JSON 自带 bpm，则把 start/duration 当作拍数直接使用。
5. 时值以四分音符一拍换算，支持整拍、半拍、附点、十六分音符和三连音；量化网格为1/960拍（60 BPM时约1ms），不足六十四分音符的空隙并入前一个音。
6. 音高映射到口琴音域（低音1～高音7，另含最高do）：先整体八度移调，仍超范围的个别音再折回八度，提示区会注明数量。
7. 原 .json 不会被修改；导入后曲名取 JSON 的 title（没有则取文件名），谱面进入编辑器，可继续修改、试听、导出或“保存 TXT”。

九、曲库与曲谱文件夹
1. 窗口左侧是“曲库”：启动时自动读取EXE同目录的“简谱”文件夹里的三个子目录——简谱\TXT（软件保存的txt）、简谱\MIDI（mid/midi）、简谱\JSON（json曲谱），列出曲名与类型，例：天空之城 【JSON】。
2. 在曲库里选中一首即开始导入，不用再点“导入”选文件；导入过程与手动导入完全相同（多音轨会弹窗选轨，有未保存修改会询问），导入后该曲在列表里高亮。顶部输入框可按曲名筛选，底部“刷新曲库”重新扫描；用“保存 TXT/另存为”存下新曲谱后列表会自动刷新。
3. 想添加其他曲谱仍然可以点“导入 TXT / MIDI / JSON”手动导入；把曲谱文件放进对应子文件夹后，下次启动（或点“刷新曲库”）就会自动出现。发布包的简谱\JSON里已放入GTIartist曲库（62首），可直接导入。
4. 点“导入 TXT”“导入 MIDI”“导入 JSON”时，文件对话框会自动打开对应的子目录；“保存 TXT”“另存为”定位到TXT，“导出 MIDI”定位到MIDI。若分类子目录不存在，对话框会退回“简谱”文件夹，再退回EXE所在目录，不会报错。
5. 界面为左右两栏，按“演奏 / 曲谱文件 / 本机试听 / 曲谱编辑 / 快捷键与设置”分成卡片；开始键为蓝色主按钮、停止键红色。路径太长时单行省略号显示，鼠标悬停可看完整路径；窗口可自由缩放，右侧编辑器超出高度时可滚动。
