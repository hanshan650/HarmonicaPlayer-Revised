# HarmonicaPlayer-Revised

在《三角洲行动》里自动演奏口琴的 Windows 桌面工具：把简谱（数字谱）转成游戏内的口琴按键演奏，
还可以编辑与保存 TXT 简谱、导入 MIDI 与 JSON 曲谱、用真实口琴采样本地试听、导出标准 MIDI。

> **来源声明**：本项目基于原作者 [lanselanlanxi-wq/HarmonicaPlayer](https://github.com/lanselanlanxi-wq/HarmonicaPlayer)
> 修改而来（基线 v0.3.3，`212316e`），新增了 MIDI/JSON 导入、音轨选择、曲库侧栏与新界面等功能。
> **原代码版权归原作者**，本项目不是官方版本；逐项修改内容、许可与版权说明见 [NOTICE.md](NOTICE.md)。

## 功能

- **曲库侧栏**：启动自动读取 EXE 同目录的 `简谱\TXT`、`简谱\MIDI`、`简谱\JSON`，按曲名列出；**选中即导入**，顶部可筛选、底部可刷新；手动导入（`导入 TXT / MIDI / JSON`）照旧。
- **音轨选择**：多音轨曲谱（MIDI / JSON）导入时弹窗列出每条音轨（编号、名称、音数、音域、平均音长、同时发声音数），导入后可用“演奏音轨”下拉框随时换轨，不必重新导入文件。
- **界面**：左右两栏 + 功能卡片（演奏／曲谱文件／本机试听／曲谱编辑／快捷键与设置）；开始键主色按钮、停止键红色，**中间竖条可左右拖动调整曲库栏宽度**，窗口可自由缩放，长路径省略号 + 悬停提示。

- 曲谱：`HarmonicaPlayer/1` TXT（`@format/@title/@bpm/@gap` 文件头），兼容旧纯音符 TXT 与“歌名 bpm100.txt”命名。
- 导入：MIDI（Format 0/1，.mid/.midi）、JSON（任何含 `notes` 数组的对象：pitch / start / duration，可选 bpm / title / track）。
- 试听：内置 Hohner Special 20 真实口琴采样；从头或从光标试听、当前音符高亮、音量 0～100%（默认 60%）。
- 导出：标准 MIDI Format 0、单轨、9600 PPQ、GM 口琴音色，不含采样音频。
- 演奏：3 秒倒计时后向目标窗口发送键鼠；默认开始 F6、停止 F8，可自定义。
- **音频转谱（可选附加组件）**：装好后可把音频（歌曲／哼唱／口琴录音）转成 MIDI 再导入成简谱。
  模型与环境约 9.3 GB，**不随分发包提供**，需要自行安装，见下文「音频转谱」。

## 下载与使用

1. **下载**：到 [Releases](https://github.com/hanshan650/HarmonicaPlayer-Revised/releases) 下载 `HarmonicaPlayer-Revised-vX.Y-win-x64.zip`。
2. **解压**：完整解压到一个普通文件夹（不要直接在压缩包里双击 EXE，否则同目录的“简谱”说明会丢）。
   程序是自包含单文件，**不需要安装 .NET，也不联网**。
3. **双击** `HarmonicaPlayer.exe` 即可运行。首次运行可能提示“未知发布者”（未做代码签名），
   点“更多信息”→“仍要运行”即可；杀毒软件误报时把所在文件夹加入白名单。
   设置写在 `%LOCALAPPDATA%\HarmonicaPlayer\settings.json`，不写入程序目录。
4. **放曲谱**：EXE 同目录的 `简谱\TXT`、`简谱\MIDI`、`简谱\JSON` 放入自己的曲谱，启动后左侧曲库自动列出，点一首即导入；
   也可以用“导入 TXT / MIDI / JSON”手动导入。
5. **演奏**：先“本机试听”核对旋律；实际演奏时取消“仅日志测试”，在游戏里取出口琴后按开始键（默认 F6），
   3 秒倒计时内切回游戏，停止键默认 F8。权限应与游戏匹配（必要时以管理员运行），游戏建议无边框窗口；
   演奏期间除停止键外不要操作键鼠。
6. 发布包里还带了一份 `首次运行说明.txt`，可直接发给使用者。

## 试听与 MIDI 的细节

- 试听从头或从光标开始，播到曲末不循环；停止后恢复开始试听前的编辑光标，再次试听使用最新内容。
- 音高：中音1=C4（MIDI 60）、低音1=C3、高音1=C5、最高do=C6，#升半音；不按原谱调号自动移调。
- 每音按谱面拍数占时，末尾扣除当前 gap 作为留白；休止按完整时值静音。试听、MIDI 与游戏演奏的拍点和总时长一致（游戏按住时间额外少 12ms 的准备量），所有入口执行同一套最短音校验。
- 导出 MIDI：Format 0、单轨、9600 PPQ、固定速度、GM 口琴音色（22 号）、力度 96；先写临时文件再替换，失败保留原目标；不含采样音频，未定义拍号（外部软件可能显示为默认 4/4，不影响时值）。
- 贡献来源与历史采纳范围见 [CONTRIBUTIONS.md](CONTRIBUTIONS.md)。

## 音频转谱（可选附加组件）

装好之后，界面「曲谱文件」一栏会多出一个可用的 **「音频转谱」** 按钮：
选一段音频，本机用开源模型 [SheetSage2](https://huggingface.co/m-a-p/SheetSage2) 转成 MIDI，
再走已有的 MIDI 导入流程变成可演奏的简谱。

**它不在发布包里**，因为模型权重（SheetSage2 218 MB + MERT-v2-FullSong 2.4 GB）与
PyTorch 环境合计约 9.3 GB，而主程序的分发包只有 163 MB；而且权重许可是**非商业**的
（CC BY-NC 4.0），适合由使用者按需自行获取。

**安装：在软件里点一次「音频转谱」即可。** 检测到环境不存在时会自动弹出安装向导，
点「开始安装」就行——不需要预装 Python（安装器自带嵌入式 Python 3.11），
有 N 卡自动装 CUDA 加速版（下载约 5.5 GB），没有就装 CPU 版（约 2.8 GB）。
装完会真跑一次显卡内核测试：不兼容时自动换 CUDA 12.8 版（RTX 50 系需要），
再不行自动降级 CPU 版——不会出现"装完才报错"的情况。
中途取消不白费，下次接着装。装完环境就在软件 EXE 旁的 `音频转谱\` 目录，
主程序自动认出，不用任何配置。

> 从仓库构建的开发者也可以手动装：`extras\audio-to-score\setup.ps1`
> （需自备 Python 3.10/3.11；venv 布局，装出的目录**不能拷到别的电脑**）。

完整说明、参数、性能实测与常见问题见 [extras/audio-to-score/README.md](extras/audio-to-score/README.md)。

实测（RTX 4060 Laptop + bf16）：6 分 13 秒的音频 **43.5 秒**转完（约 8.6 倍速），
显存峰值约 **2.1 GB**；口琴短句的音高序列可以做到完全正确。

> 模型是第三方产物：**权重为 CC BY-NC 4.0，只可用于非商业用途**。
> 转谱结果是**起点而非终点**——节奏细节与复杂编曲仍需人工在简谱编辑里过一遍。

## 曲谱目录

```text
简谱\
  TXT\    *.txt    软件保存的 HarmonicaPlayer/1 曲谱
  MIDI\   *.mid    导出或收集的 MIDI
  JSON\   *.json   JSON 曲谱（notes 数组）
```

导入与导出对话框会自动定位到对应分类（子目录不存在时退回 `简谱`，再退回 EXE 目录），省去每次手动找路径。

暂不包含暂停、播放列表、动态BPM或和弦。TXT继续使用 HarmonicaPlayer/1，无需转换旧谱。MIDI 与 JSON 可导入用于生成简谱正文，但导入结果是单音旋律，不支持和弦与变速。

## TXT格式

旧纯音符TXT仍可导入。文件名可写“歌名 bpm100.txt”“歌名_BPM100.txt”“歌名-bpm100.txt”“歌名 bpm 100.txt”。BPM为20～300整数。

建议在软件内保存新格式：

```text
@format=HarmonicaPlayer/1
@title=节奏示例
@bpm=120
@gap=20

1 2_ 3_ 5 — |
0 6. 5_ 1 |
```

- 文件格式版本与软件版本独立。新格式要求@format和@bpm；@title可省略，导入时用文件名。界面曲名不能为空。
- 文件头与正文之间必须有空行。同名字段不能重复（不区分大小写）。未知字段提示后原样保留，但不解释其作用，例如@time不会改变节拍。
- 文件头与文件名BPM冲突时以文件头为准并提示。没有BPM时沿用界面有效速度，界面无效则使用最后有效设置。
- @gap可省略，省略时使用20ms（旧纯音符TXT也一样）。填写时必须是10～5000的整数；空值、越界、重复字段会报错。保存时自动写入当前间隔。间隔不会改变每拍总时长，但会缩短按住时间，仍受最短音校验限制。
- UTF-8（记事本“ANSI/GBK”保存的旧谱也能读，会提示建议另存为 UTF-8），最大1MB。文件头不要粘贴进音符编辑区。
- 保存前检查曲谱、速度和间隔；先写同目录临时文件再替换目标。验证或写入失败不覆盖已有目标。
- 不含文件头的旧版本不识别新格式；旧版兼容请单独复制正文到TXT，并在旧版设置BPM。

## 音符规则

| 写法 | 含义 |
|---|---|
| 1～7 | 中音，一拍 |
| 【1】～【7】 | 高一个八度 |
| （1）或(1) | 低一个八度 |
| 【【1】】 | 高两个八度do，仅此音 |
| #1、【#1】 | 升半音 |
| 0 | 休止一拍 |
| 5_、5__ | 半拍、四分之一拍 |
| 5.、5_. | 1.5拍、0.75拍 |
| 5 —、0 — | 增加一拍 |
| 5:1.25 | 同一个音总共持续1.25拍 |

冒号指定总拍数，大于0且不超过64，不可再混用下划线、附点或延长符。最高do的时值写在括号外，如【【1】】:1.25。空格、换行、小节线不增加停顿；小节线不执行满拍检查。扣除12ms准备和间隔后至少按住40ms；不足时提示区会给出建议（减小“音符间隔”或降低速度），不再自动降速。

## 测试与打包（Windows + .NET 8 SDK）

```powershell
dotnet run --project .\Tests\ParserTests.csproj -c Release
dotnet run --project .\Tests\WindowsSmoke\WindowsSmokeTests.csproj -c Release
powershell -NoProfile -ExecutionPolicy Bypass -File .\Build-Release.ps1
```

`Build-Release.ps1` 先跑上面两道测试门禁（任一失败即停止），再发布自包含单文件 EXE 并生成
`bin\Release\HarmonicaPlayer-Revised-v<版本>-win-x64.zip`：包含 EXE、说明、模板、示例与 `简谱` 文件夹内的曲谱。
界面测试使用可控音频替身，不发声、不发送游戏按键；也可设 `HARMONICA_UI_SHOT=<目录>` 把界面渲染成 PNG 便于核对。
